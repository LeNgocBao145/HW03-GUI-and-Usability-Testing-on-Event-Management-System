# Post-Task Probe Answers - P01

| Question ID | Question | Participant Answer |
|---|---|---|
| Q01 | What part of the task was easiest? | Finding an event after using search and Upcoming was straightforward. |
| Q02 | What part was most confusing? | Save Event looked close enough to Register that I first treated it as reserving a place. |
| Q03 | Was the event information sufficient for deciding whether to register? | Yes for topic, date, and location; a clearer registration deadline would improve confidence. |
| Q04 | How clear was the role-selection and registration process? | Selecting a card was clear after the checkmark appeared, but the word Commander was unfamiliar. |
| Q05 | When something unexpected happened, did the interface help you recover? | Not directly. I recovered because Save Event did not change the registration state, then I searched for another action. |
| Q06 | Did the system feel fast enough? | Yes; response time felt acceptable during the task. |
| Q07 | Did you trust that the registration was recorded successfully? Why? | Mostly. Pending review looked persistent, but I expected a separate success message after submission. |
| Q08 | What is the first thing you would improve? | Make Register visually primary and show a clear confirmation after submission. |
