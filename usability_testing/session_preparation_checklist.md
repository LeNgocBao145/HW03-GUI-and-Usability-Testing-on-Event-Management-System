# Session Preparation Checklist

## Before Recruiting

- [ ] Task scenario reviewed
- [ ] Metrics defined
- [ ] Moderator guide reviewed
- [ ] SUS prepared
- [ ] Probe questions prepared
- [ ] Privacy rules reviewed

## Before Each Session

- [ ] EMS available
- [ ] Correct URL
- [ ] Account authenticated
- [ ] Upcoming event with open registration exists
- [ ] Participant starting state reset
- [ ] Timer ready
- [ ] Recording ready
- [ ] Observation notes ready
- [ ] Consent confirmed
- [ ] Participant contact masked in repository

## After Each Session

- [ ] Timer stopped
- [ ] Outcome recorded
- [ ] Errors counted
- [ ] Hesitations counted
- [ ] Interventions recorded
- [ ] SUS completed
- [ ] Probe answers recorded
- [ ] Technical interruptions separated
- [ ] Session ready for `participant-session-processor`
