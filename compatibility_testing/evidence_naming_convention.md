# Evidence Naming Convention

Use:

`<Screen>_<OS>_<Browser>_<DeviceClass>_<Result>_<Sequence>.png`

Examples:

- `B1_WIN11_CHROME_DESKTOP_PASS_001.png`
- `B2_IOS_SAFARI_PHONE_FAIL_001.png`
- `B3_MACOS_FIREFOX_DESKTOP_PASS_001.png`

Each screenshot must visibly show:

- EMS URL
- operating system
- browser
- device or resolution
- student-ID email overlay: `MSSV@....edu.vn`
