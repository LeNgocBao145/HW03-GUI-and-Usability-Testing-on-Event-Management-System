# Compatibility Test Plan

Each of B1, B2, and B3 must cover:

- 3 operating systems
- 5 browsers
- 3 device classes

Example operating systems:

- Windows
- macOS
- Android or iOS

Example browsers:

- Chrome
- Firefox
- Safari
- Edge
- Opera or Samsung Internet

Device classes:

- Desktop
- Tablet
- Phone

This plan does not require all 45 combinations.

For each screen:

- every selected OS must appear at least once
- every selected browser must appear at least once
- desktop must appear at least once
- tablet must appear at least once
- phone must appear at least once
